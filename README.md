# YOS Taxi Operations

iPhoneだけで使う沖縄夜勤タクシー営業の実用PWAです。

## v1でできること

- 営業開始・乗車・降車・休憩・メモ・営業終了
- 時刻、営業状態、乗車時間、休憩時間の自動記録
- 売上、乗車回数、平均単価、営業時給の自動計算
- 端末内自動保存、オフライン利用
- YOSへ営業報告を共有／コピー
- ProjectY入力ログ互換CSVとJSONバックアップ
- ProjectY運行データ、Mission Controlへの導線

## 安全

運転中の入力は禁止。必ず安全な場所へ停車して操作してください。

## データ方針

認証情報を保持しません。営業データは端末内に保存され、CSV・JSONとして書き出せます。ProjectYへの正式保存はYOS経由または既存入力フローで行います。
